### Featured project

**Divvy Bike-Share Cleaning Pipeline** — [GitHub Repo](https://github.com/feghali1994/cyclistic_data_cleaning_script)

A reproducible pandas pipeline that turns ~5M rows of raw, messy ride records into an analysis-ready dataset. Rather than silently dropping problem rows, it flags and exports them (DST-ambiguous timestamps, negative durations, missing coordinates) so the cleaning decisions stay auditable. Includes datetime parsing, timezone localization for naive local Chicago time, derived ride-duration fields, and dtype optimization to cut memory use.
